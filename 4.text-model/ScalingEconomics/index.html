Scaling 经济学：训练成本、推理成本与收入的 ROI 框架#

起因：与 ScalingLaws.md 配对。技术侧笔记回答"有哪些旋钮、每个旋钮的技术依据"；本文回答"每个旋钮值多少钱"——把 scaling 的技术叙事翻译成 CapEx / OpEx / 收入三本账与全成本系数（κ），并回答两个战略问题：模型大小是否到了瓶颈、未来是综合大模型还是垂类小模型。

0. 核心论点#

  1. "模型大小到瓶颈"是伪问题的表述方式。 真问题是：每一美元买到的新能力增量在哪个旋钮上最大。参数轴的边际 $ 收益递减是幂律的数学必然，所以行业把增量预算搬去了别的轴（RL post-training、推理时计算、agent 系统层）。scaling 会继续，但 scaling 的定义已经变了。
  2. "综合大模型 vs 垂类小模型"是假二元。 收敛中的产业结构是两层：大模型是能力工厂（资本品），小模型是部署载体（消费品）。要算的不是"选哪个"，是"处在产业链哪一层、流量分母够不够"。
  3. 真实成本是全成本，算力只是最可见的一项。 数据（获取阶梯）、实验（失败金字塔）、人力（边际替代）、风险（期望损失）都应入账；同等效果下系数越低效率越高（κ，见 2.5），一切模型竞争最终都是 κ 竞争。

1. 理论层：四个经济学事实#

1.1 幂律 = 边际收益递减的数学表达#

  • L ≈ A·C^(-α)，loss 对算力是对数线性：算力乘 10，loss 只降一个固定比例
  • 推论一：每代保持同等 loss 降幅，算力必须指数增长（历史节奏约 4~10x/年有效算力，来自硬件迭代 + 资本开支增长）
  • 推论二：每一档同等提升的价格标签指数式变贵 → 决策变量从"能不能"变成"值不值"
  • 这就是为什么 scaling 的问题最终是 ROI 问题

1.2 Chinchilla 是"训练最优"，真实世界是"全生命周期最优"#

Chinchilla 优化的目标函数里只有训练成本，模型训完就评估。但部署世界里训练是 CapEx（一次性），推理是 OpEx（每次调用都在付）。

算例（量级示意）：

项目 数值 口径
GPT-4 级训练 ~$50-100M ~2e25 FLOPs；H100 $2/GPU·hr、40% MFU
高流量推理 ~$210 万/天 10 亿次调用/日 × 700 token × $3/1M 混合价
两年生命周期推理 ~$15 亿 730 天累计
推理 : 训练 ≈ 15 : 1 高流量模型

推论：

  • 最优模型大小不是技术常数，是 流量 × 单价 × 生命周期 的函数
  • 高流量模型的 TCO 里训练成本摊薄为噪声；低流量场景自训模型是灾难（固定成本没有分母）
  • 类比：租车 vs 买车。没有流量分母，租（API）优于买（自训）
  • 这正是 ScalingLaws.md 第 3 节（过训练）发生的经济原因：Llama 2 的 290 TPP、Gemma 2 的 889 TPP 不是技术偏好，是 TCO 结构决定的

1.3 MoE 把"能力"和"成本"解耦成两个变量#

  • 总参数 = 知识容量（CapEx 侧，装多少）
  • 激活参数 = 单位推理成本（OpEx 侧，想多远）
  • DeepSeek V3：671B 总参数 / 37B 激活，官方训练成本 $5.576M——同代能力比 GPT-4 时代便宜约一个量级
  • 推论："变大"和"变贵"脱钩了。前沿可以继续加大总参数（装知识），只要激活参数被按住
  • 所以"大小是否瓶颈"要拆开答：总参数没瓶颈（装知识还有空间）；激活参数受推理经济学约束；真正的稀缺资源变成了高质量数据和 RL 环境（对应 ScalingLaws.md 第 5、10 节）

1.4 能力 → 收入的映射是阶跃函数，不是线性函数#

收入
 │              ┌──────────── 同质化区：增量质量 ≈ 0 增量收入
 │              │             （过阈值后比价）
 │           ┌──┘
 │           │ ← 阈值：跨过去解锁整条产品线（0→1）
 │        ┌──┘
 └────────┘
   不可用区：收入 = 0（任务不可用，客户直接不用）
 └────────────────────────────────→ 模型能力
  • 阈值之下：收入 = 0
  • 跨过阈值：解锁产品线。大模型的边际价值高度集中在"还没跨阈值的最后几个点"
  • 阈值之上：同质化比价。小模型的机会全在"已跨阈值的长尾"
  • 这条曲线是"要不要继续 scaling"的真正决策函数，榜单分数不是

2. 框架层：三本账与全成本系数#

2.1 账本 A：训练（CapEx）#

C_train ≈ 6 × N_active × D（FLOPs）× $/FLOP
  • $/FLOP：H100 租金 $2/GPU·hr @ 40% MFU ≈ 4e14 FLOP/s → 约 1.4e-18 美元/FLOP
  • 算例：
模型 训练 FLOPs 估算成本 备注
GPT-4 级 ~2e25 $50-100M 2023，公开推算
Llama 3.1 405B ~3.8e25 ~$60M+ 30.84M H100·hr
DeepSeek V3 ~3-4e24 $5.576M 官方数：MoE + FP8 + 工程
  • 前沿能力的单位成本在按代际通缩（~10x/代），这不是"scaling 到头"，是 scaling 的工程化红利
  • 分摊口径：C_train ÷ 生命周期总 token。高流量下摊到每 1M token 不足 1 美分；低流量下它就是全部成本——这决定了"自训还是租"
  • 口径提醒：本账本只含最终 run 的算力；全成本口径（数据/实验/人力/RL 环境）见 2.5-2.7，DeepSeek $5.576M 的口径真相见 2.5

2.2 账本 B：推理（OpEx）#

  • 每 token 成本 ≈ 2 × N_active × $/FLOP（吞吐模式）；物理底见 inference-perf-theory.md（decode 带宽受限：TPOT_min = 权重字节 ÷ 带宽）
档位 成本价（每 1M token） 说明
30B 激活级 ~$0.1-0.5 批量吞吐模式，mini 档
300B 激活级 ~$5-15 frontier 档
推理模型 再 ×5-20 thinking token 乘数
  • mini 与 frontier 之间 ~100x 价差的结构分解：激活参数比（~20x）× thinking 乘数（~5x）× 利用率与毛利差异。是物理结构决定的，不是定价任性
  • 价格通缩：同级能力市场价约两年降 ~100x（GPT-4 输出价 $60/1M → mini 级 $0.6/1M），"单位智能价格"按摩尔节奏通缩
  • Jevons 悖论：单价降 → 可用场景爆炸 → 推理总开销反而涨。"模型变小"与"推理市场变大"同时成立
  • test-time compute 的经济学本质：把训练时的一次性 CapEx 换成每次调用的可变 OpEx，给了一个新的"花钱买能力"的入口（对应 ScalingLaws.md 第 4.2 节）
  • RL 训练中的 rollout 同样是推理形态的成本，账本 A/B 的边界在 RL 时代正在重新划分，见 2.6 第 6 条

2.3 账本 C：收入（最容易被忽略的非线性）#

三种收入结构：

结构 特征 典型场景 谁赚钱
门槛型（winner-take-most） 能力不够客户直接不用 agent 编程、长程规划、20 步推理链 大模型：最难 20% 任务 + 首发窗口定价权
同质型（比价） 过阈值后质量无差异 分类、抽取、摘要、RAG 问答 小模型：成本领先者
教师型（隐形 B2B） 大模型给小模型产数据/蒸馏/奖励标注 合成数据、蒸馏教师、judge 大模型当"小模型的工厂"

决策规则：

用大模型 iff ΔRev（被大模型救回的那部分流量的价值） > ΔCost（大小价差 × 全部流量）
  • 分子只算"小模型失败、大模型成功"的流量 × 单 query 价值
  • 常见错误：分子用全量流量 × 质量差，会高估大模型收益一个量级

2.4 三本账合并：TCO 视角#

TCO = C_train 分摊 + C_post-train 分摊 + C_inference（高流量下占 90%+）+ 数据成本 + 运维
  • 训练侧的"贵"从来不是大厂的问题（有流量分母）；问题是能不能赚回门槛型收入
  • 推理侧的"贵"是所有部署方的问题；所以所有优化（蒸馏、量化、级联、路由）都在攻这一项
  • 本节是第一近似；数据、实验、人力、风险的完整口径见 2.5-2.7

2.5 效率系数 κ 与数据获取阶梯#

三本账只算了最可见的项（算力）。真实成本里，数据、实验、人力的占比可能更高。把所有成本归一到"单位能力"上，得到效率系数：

κ_train = 全成本 ÷ Δ能力
        = (算力 + 数据 + 实验摊销 + 人力 + 资产摊销 + 风险期望) ÷ 能力增量

κ_serve = 全链路服务成本 ÷ 有效查询(成功且被用户接受；失败重试不进分母)

同等效果下 κ 越低，效率越高。κ 是公平比较"谁的美元变成能力"的唯一口径——公开的"训练成本"几乎都犯同一个口径错误：DeepSeek 的 $5.576M 只是最终一次 run 的算力，论文脚注自己写明不含前期研究与消融。那是边际成本，不是 κ。

数据获取阶梯#

数据成本不是单一数字，是一条按获取方式分档的阶梯：

档位 边际成本 质量上限 前提资产
人工标注 $0.5-5/条（简单），$10-100+/条（专家域） 最可控，线性扩展 标注团队/外包
规则/模板合成 ~$0.001-0.01/条 规则设计者水平 领域知识
蒸馏强模型 教师推理费（500 token 样本 @ mini 档约 $0.0003/条） = 教师水平 强模型（自研或 API）
线上产品回流 ≈ 0（边际） on-policy 溢价：就是部署分布上的数据 线上产品 + 清洗管线
可验证环境（RLVR） ≈ 0（每条奖励：单测/答案对错） 环境保真度 沙箱/引擎/真机
  • 蒸馏 vs 人工的量级：100 万条 500-token 样本，蒸馏约 $300，人工 $50 万起——三个数量级的价差，但蒸馏质量被教师封顶
  • 产品回流的精确表述：(a) 订阅收入覆盖 serving 成本，推理不再是纯支出；(b) 会话本身就是训练素材的生成过程，一次投入两次产出。两个修正：隐式信号（点击/采纳/编辑/停留）→ 训练信号的转换需要奖励模型 + 清洗管线（固定成本）；合规与脱敏是持续开销。所以是边际免费，不是零成本
  • 阶梯的结构性规律：越便宜的档位，前提是先拥有越贵的资产。 教师档要有强模型，回流档要有产品，环境档要有 infra。数据系数是资产存量的函数，不是自由选择——这解释了为什么有产品的公司天然数据成本低
  • 推论（反直觉的定价行为）：大厂慷慨的免费额度 = 数据采购预算，烧 OpEx 买 on-policy 数据
  • Physical AI 站在阶梯最贵的位置：真机数据采集成本远超一切文本档位

2.6 全成本模型：实验系数、人力系数与七项补充#

实验系数：失败金字塔#
  • 每个最终 run 底下压着消融与失败分支：Chinchilla 拟合用 400+ 个模型，MoE scaling 论文普遍 300+（索引见 ScalingLaws.md 第 13 节）；经验量级：实验：最终 ≈ 3-10x 算力
  • scaling law 本身是实验系数的压缩技术：用小 run 买信息、外推大 run，把"实验一遍"降为"拟合一条曲线"。Gadre 2024（过训练区域可靠外推，arXiv:2403.08540）在这个框架里的准确位置：把实验系数砍了一个量级
  • 配方折旧：FP8/MoE 工程一年内变行业标准，效率优势的半衰期约 12-18 个月（论文、挖人、开源三条侵蚀路径）→ 系数优势要求持续创新，或结构性资产（数据回流、自研芯片）
人力系数：与其他系数的边际替代#
  • 一个研究员的价值 = 他压低的其他系数：年薪 $1M 的人，只要在 $100M 的 run 上省 2% 算力、或砍掉一次失败 run，就回本
  • 人力与算力在边际上可替代，存在最优配比
  • 国别劳动套利（同等算法人才薪酬差 2-5x）是 κ 国别差的来源之一，不只是算法差异
其余必须入账的七项#
  1. eval/质检成本：效果可测性是 κ 的前置成本——"同等效果"测不准，所有系数比较都是自欺。垃圾 eval → 错误信号 → 整个 RL run 报废，是最贵的隐性失败（评估走向经济价值量化的意义，见 PercyLiang.md 的 EconEvals）
  2. 部署侧隐性成本：集成、护栏、监控、失败兜底。真实自动化是混合系统：模型失败的流量转人工，人工兜底成本必须进 κ_serve。自动化边界 = 混合成本曲线的最优点——fail-loud@node + fail-soft@batch 的哲学本质上就是在管理这项成本
  3. 利用率与峰值税：自建集群按峰值容量付费，流量有峰谷；API 厂商把 N 个客户的峰谷池化。同样的硬件和模型，自建的有效 $/token 更高——这是"小规模用 API"的结构性原因，比"训练贵"重要
  4. 时间与折旧：模型是折旧资产（能力通胀，今天的前沿 ≈ 三年后的 mini）；训练周期 3-12 个月，期间目标在移动。市场移动快时买（API），稳定时建
  5. 风险成本：训练 run 失败（第 3 周 loss spike 报废几千万美元）、供应商 sunset（API 模型下线）、供应链中断。按期望损失进 κ
  6. RL 拆账：账本 A 应拆为 C_pretrain + C_RL，其中 C_RL = 环境 CapEx + rollout 推理费 + 奖励模型训练与服务。rollout 是推理形态的成本——RL 训练账单里越来越大的一块是"生成 token 的钱"，o 系/GLM-5.3 时代 RL 算力已与预训练可比（见 ScalingLaws.md 第 7-8 节）
  7. 知识所在地原理：蒸馏只能搬运教师已有的公开能力；私有知识（自己的客服日志、业务数据）任何教师都不存在，只能走标注/产品回流。这是垂类模型存在的根本原因——第一支柱是私有知识，第二支柱是专业化增益（窄分布上，蒸馏出的专用小模型可以反超教师，因为容量全部给了单一分布）。"垂类护城河在数据飞轮"由此获得成本侧的严格证明

2.7 统一图景：κ 竞争#

  • 所有 AI 竞争都是 κ 竞争：训练侧比"钱变能力的效率"，服务侧比"能力变钱的效率"
  • 每个系数都有自己的获取技术在进步：算法效率约 8-16 个月翻倍（Erdil & Besiroglu，arXiv:2212.05853，不同修订版口径）、数据沿获取阶梯下行、scaling law 压实验、工具压人力 → κ 整体通缩，与账本 B 的 Jevons 悖论是同一枚硬币
  • "哪个系数剩余空间最大，增量投资就去哪"——这是 ScalingLaws.md 第 10 节旋钮轮转在成本空间的镜像。技术叙事与成本叙事在此汇合

3. 回答两个战略问题#

3.1 大小到瓶颈了吗？还会 scaling 吗？#

  • 参数旋钮：边际 $ 收益递减 + 数据墙（高质量公网文本十几 T token 量级，重复数据按幂律衰减收益）。递减是真的，但没有停——前沿仍在 1e26+ FLOPs 量级往上走
  • scaling 换轴：增量预算从"预训练一次成型"搬到 RL 后训练（ScalingLaws.md 第 7-8 节，GLM-5.3 受控实验）、推理时计算、agent 系统层。每次"最值得转的旋钮"都不是上一个——经济逻辑（资本流向边际收益最大的轴）和技术逻辑（旋钮剩余空间）在这里是同一句话
  • 真正的天花板不是技术，是宏观 ROI 验证周期：行业年 capex 数千亿美元 vs AI 直接收入百亿美元级，比值悬而未决。收入验证跟上 → 继续；跟不上 → 消化期回调（资本周期，不是终局）
  • Ilya 的"从规模化时代迈向研究时代"（见 SSI-Ilya.md）与唐杰的"旋钮轮转"是同一判断的两种表述：参数轴的油水在变薄，下一个突破来自别的轴
  • 判断：总参数继续涨（知识容量），激活参数被推理经济学按住，增量投入流向 RL 环境、数据质量、推理时计算

3.2 未来是综合大模型还是垂类小模型？#

收敛中的双层产业结构（不是预测，是正在发生）：

  • 上层：少数前沿 MoE = 能力工厂。资本密集、规模效应强、赢者通吃倾向；产品是"能力"本身（教师、合成数据、最难任务、首发窗口）
  • 下层：海量蒸馏/微调小模型 = 部署载体。任务分布窄 → 95% 质量 × 1-10% 成本，外加低延迟、私有化、合规、可控
  • 两层之间是传送带：蒸馏、合成数据、路由/级联——这条传送带本身就是生意
  • 时间维度：能力通胀，今天的前沿 ≈ 三年后的商品 mini。所以垂类小模型的护城河不在模型（会被追平），在数据飞轮 + 任务理解 + eval 体系
  • 对知识挖掘/agent 工程的落位：大模型当离线工厂（标注、挖掘、合成、judge），小模型当在线载体（蒸馏/微调后承载高频流量）

4. 应用层：选型矩阵与 ROI 模板#

4.1 模型选型二维矩阵（质量阈值 × 调用量）#

                      高质量阈值
                          │
     直接调 API 大模型     │     级联 cascade
     （租，别自建）       │     （小模型主力 + 大模型兜底）
   ───────────────────────┼───────────────────────
     等/用商品 mini        │     自蒸馏垂类小模型
   （能力通胀会送上门）   │     （ROI 最优区：价差×量 > 蒸馏成本）
                          │
                      低质量阈值
        低调用量 ←────────┴────────→ 高调用量

矩阵之外还有一条时间轴：模型是折旧资产（能力通胀，今天的前沿 ≈ 三年后的 mini），训练周期本身 3-12 个月、期间目标在移动。市场移动快时买（API），市场稳定时建（蒸馏/自训）。

4.2 自建垂类小模型的三个前提（同时满足才动手）#

  1. 私有数据飞轮已经在转（标注/挖掘产出持续回流）
  2. 任务分布稳定（不会三个月变一次）
  3. 量够大：升级流量 × 价差 > 蒸馏 + 维护成本（经验上日百万级 token 调用是起步线）

4.3 ROI 计算模板（六步，可对接挖掘 pipeline）#

  1. 用大模型离线把 query 按难度分桶（mining/eval 基建可做）
  2. 每桶测四个数：小模型成功率 s_s、大模型成功率 s_b、单 query 价值 v、桶流量 q
  3. 级联总成本 = Σ q_i × [(1-p_i)·c_s + p_i·c_b]；p_i 是升级率，是成本旋钮
  4. 级联总收益 = Σ q_i × (s_b - s_s) × v_i；只算被救回的流量
  5. 解出 break-even 的 p 和 v
  6. 每季度重算：c_b 以约 10x/两年的速度通缩，今天不划算的升级率，明年可能就划算。这是动态决策，不是一次性架构选型

5.1 样本与口径#

5.2 海外四家#

OpenAI：资本-产品飞轮的标准样本

  • 供血：累计融资 $60B 级（2025.03 软银领投 $40B，估值 $300B）；Stargate 计划 $500B 量级（软银/甲骨文/MGX 合资，多年口径）；微软深度绑定（Azure 采购承诺 + 分成，报道口径 20% 级）
  • 烧钱：GPT-4 级训练 ~$100M；GPT-5 代际单 run 传闻 $500M-1B（含实验）；年推理开销数十亿美元级
  • 收入：ARR ~$13B（2025 中），ChatGPT 周活 7 亿+，订阅占大头
  • 收入结构：门槛型（能力首发窗口）+ 同质型（订阅/API），教师型（GPT 系当蒸馏教师）刚起步
  • 数据档位：产品回流（阶梯第 4 档），免费层是"免费额度=数据采购预算"的最典型实践
  • κ 特征：训练侧 κ 不占优（capex 最重），但流量分母全球最大，资产摊销摊得最薄。风险：收入/烧钱比仍 <1，是第 3.1 节"宏观 ROI 验证期"的头条样本

Google：唯一每个系数都有结构性优势的玩家

  • 供血：广告主业现金流（年利润千亿美元级），2025 capex 指引 ~$75B，2026 更高
  • 算力系数：自研 TPU（v5e → Trillium → Ironwood），自用单 token 成本显著低于租 GPU（幅度各方估算不一）
  • 数据系数：Search/YouTube/Android 全分发面，AI Overviews 月触达 15 亿+用户
  • 收入：间接变现为主——云收入两位数增长 + 搜索护城河；模型本身不背收入指标
  • κ 特征：算力、数据、分发三个系数同时占优，且"输得起"（模型业务失败不伤主业）。全行业唯一不需要靠卖模型收回训练成本的玩家

Anthropic：门槛型收入纯度最高

  • 供血：累计融资 $30B 级（2025.09 估值 $183B）；算力绑定 AWS Rainier（50 万 Trainium2）换折扣
  • 收入：ARR 从 2024 底 ~$1B 涨到 2025 中 ~$5B 级；绝大部分来自 API/企业；Claude Code 单产品年化数亿美元级（2025 中报道）
  • 收入结构：门槛型为主（代码、agent、企业工作流——能力不够客户直接不用），正好落在第 1.4 节阶跃曲线最陡的一段
  • κ 特征：单 token 变现率全行业最高，对资本的依赖相对低；放弃了分发规模，换 B 端纯度

Meta：生态防御补贴

  • 供血：广告主业，2025 capex 指引 $66-72B
  • 模型直接收入：≈0（Llama 全开源）
  • 花钱方式：$14.3B 收 Scale AI 49%（2025.06，买标注产能 + Alexandr Wang 本人）；数十亿美元级重组超级智能实验室，天价挖人
  • 算的账：防御账——开源把能力层商品化（commoditize your complement），防止能力层被单一供应商收税，保住广告毛利
  • κ 特征：人力系数逆势抬升（主动买最贵的人），训练一掷千金；换的是"模型层不可被卡脖子"的期权价值

5.3 两个特殊样本#

xAI：算力与数据的特权者，收入闭环最弱

  • CapEx：Colossus 一期 10 万 H100 用 122 天建成（2024.12）；Grok 3 宣称 2 亿 GPU 时（约 10x+ 于 GPT-4 代际估算）；融资 ~$12B 级，2025.03 与 X 合并（合并口径 xAI $80B / X $33B）
  • 数据特权：X 全量实时语料（独家回流档），特斯拉视频流（Physical AI 期权）
  • 收入：X Premium 订阅 + API，相对投入是零头
  • κ 特征：极端的"资本换期权"，赌的不是 ROI 是战略卡位；手握数据系数优势，但没有把回流变成深度产品的能力（X 的用户面 ≠ ChatGPT 的使用深度）

DeepSeek：效率系数的极限证明

  • 团队：~150 人（V3 时代），本土年轻研究员为主，无天价挖人
  • 训练：V3 最终 run $5.576M（MLA + MoE + FP8 + 自研 infra）；硬件是幻方 2021 年囤的万卡 A100 + 后续 H800——自有存量，折旧口径与租用完全不同
  • 供血：幻方量化利润，无外部 VC。这是它能极致压 κ 的制度条件：不背 ROI 验证压力
  • 定价：V3 API $0.27/$1.10 每 M（输入/输出），R1 $0.55/$2.19——o1 输出价的 1/27；R1 推理毛利率理论值 +545%（官方论文口径，假设算力全部按租价卖出）
  • 影响：2025.01.27 R1 发布次日 NVDA 单日 -17%（~$6000 亿市值，美股史上最大单日蒸发）。市场用股价承认了第 2.5 节的论点：边际训练成本 ≠ κ，效率可以击穿"capex 即护城河"的叙事
  • κ 特征：实验系数 + 人力系数全球公开样本最优；短板是收入闭环——证明了效率换得到生存权和行业话语权，换不到定价权（定价权在门槛型收入手里，第 2.3 节）

5.4 中国三系#

字节豆包：把"免费额度=数据采购"打到极致

  • 分发：豆包 app 国内 AI 应用 MAU 第一（亿级，2025）
  • 价格战：2024.05 火山引擎把主力模型降到 ¥0.0008/千 token（官方宣称比行业均价低 99.3%），此后全行业跟进——第 2.2 节"单位智能价格通缩"的主动制造者
  • 供血：广告主业 + 国内最大 AI capex（2025 估算 RMB 160B 量级）
  • κ 特征：数据系数最强（回流规模最大）+ 算力绝对量大；逻辑是把模型亏损当获客成本与数据采购预算，赌 Jevons——token 越便宜，火山云与字节生态赚得越多

阿里 Qwen：开源当云的漏斗

  • 开源：Qwen 系列是 HF 衍生模型最多的家族（10 万+ 衍生，2025 年超过 Llama，官方口径）
  • 供血：2025.02 宣布三年 RMB 3800 亿 AI 基建投入
  • 变现：阿里云百炼——权重免费，推理/微调/企业服务收钱；财报口径 AI 相关产品收入连续多季三位数增长
  • κ 特征：典型"部署载体层"打法：不抢能力工厂的定价权，赚所有人部署时的水钱；电商（交易/客服）是私有回流数据

智谱 GLM：学研人力红利 + 政府资本

  • 出身：清华 KEG（唐杰团队）；GLM-5.3 是 post-training 旋钮的受控实验样本（ScalingLaws.md 第 8 节）
  • 供血：2025 年多地国资注入（杭州/珠海/成都等，累计 RMB 十亿级），无 mega VC；已启动 IPO 辅导（2025）
  • 收入：ToB/ToG 项目 + MaaS，2024 口径 RMB 数亿级——体量小，但 B/G 路径清晰
  • κ 特征：人力系数继承学研红利；资金成本含非市场成分（自主可控的战略价值），按纯商业 κ 算不公平，按"国家级选项"算才对

5.6 四种商业模式闭环#

  1. 资本-产品飞轮（OpenAI、Google、字节）：产品回流数据 + 收入反哺 capex，门槛型与同质型混合收入；护城河 = 流量分母
  2. 主业补贴防御（Meta、Qwen）：模型业务本身不赚钱，价值 = 保护或撬动主业（广告毛利、云水钱）。开源是武器——"谁为开源买单"的两个答案：广告商和云客户（DeepSeek 是第三个答案：量化基金的战略投资，买人才品牌与影响力）
  3. 效率套利（DeepSeek、Mistral、智谱）：κ 压到极限，换生存权与话语权，不追定价权
  4. 企业深耕（Anthropic）：放弃分发规模，换单 token 最高变现与最低资本依赖

5.8 对业务方（自建垂类视角）的启示#

以客服/知识挖掘类业务为例（正是产品回流档的持有者）：

  • 你的数据系数天然在第 4 档：线上会话回流，推理成本由业务承担——按第 2.6 节知识所在地原理，这是别人买不到的档位
  • 教师档受限：最强闭源教师对你贵且有合规风险；开源教师（Qwen/DeepSeek/GLM 级）对抽取/判别类任务已够用——蒸馏成本三个数量级低于人工标注（2.5）
  • c_s 在通缩：价格战让 API 单价每 1-2 年降一个量级，级联的 break-even 升级率每季度都在变好（4.3 第 6 步）
  • 唯一不可被复制的系数优势是私有知识的挖掘质量：模型会被追平，飞轮不会——这决定了投入应该优先给数据管线而不是模型本身

6. 全生命周期 ROI 实算：开源 vs 闭源#

第 5 章是公司层的定性账。本章下钻到单模型层，把生命周期 ROI 算成数字。方法：可验证锚点（API 牌价、GPU 租金、官方披露的训练成本）用实数；不可验证的（任务质量、业务价值）作为参数显式标出——套用时按 4.3 模板实测替换。

6.1 口径#

  • 对象：单代模型，不是公司。生命周期 = 发布到被下一代替代（闭源旗舰约 12-24 个月，由能力通胀决定，2.6 第 4 条）
  • 两个视角：
  • 生产者 ROI =（模型直接归因收入 − 全成本）÷ 全成本
  • 消费者 ROI（部署方）=（业务价值 − 全成本）÷ 全成本，用标准化场景计算
  • 可验证锚点：API 官网牌价（2025-2026）、H100 租金 $2/GPU·hr、Llama/DeepSeek 官方训练披露
  • 参数假设（正文标 ⚠）：任务质量、流量结构、单 query 业务价值

6.2 生产者侧：闭源模型，单代旗舰的单位经济是正的#

先验证 1.2 的"训练摊销是噪声"：GPT-4 训练 ~$100M，生命周期服务量估 1-3T tokens，摊销 < $0.0001/1M token——比推理成本（$10-20/1M）小四个数量级。所以单代模型 ROI 几乎完全由"推理毛利 × 量"决定。

模型 训练成本 生命周期归因收入（估） 推理毛利（估） 单代直接 ROI
GPT-4（2023.03-2024.05 旗舰期） ~$100M（实验 3-10x 另计） $2-3B（2023 收入 $1.6B + 2024 上半年，ChatGPT 订阅 + API 归因） 牌价 $30/$60，成本估 $10-20/1M → 毛利 50-70% 正，量级 +100% 以上（误差大，方向可靠）

三个结论：

  1. 劳动力主导：0.3-0.5 个 FTE 的 MLOps 比全部 GPU 租金还贵——这是 2.6 第 2 条（部署隐性成本）在真实数字里的样子。有平台团队摊薄（边际人力 ≈ 0）时此项大减，那是大厂自部署的前提条件
  2. break-even 规模（按 D 中位 ~$400k 算）：
  3. vs 旗舰 API（$5.4/1M）：~100M tokens/天——正好是本场景规模。即这个量级上自部署 70B 与旗舰 API 成本打平，但质量低 7pp（⚠ 假设），只有质量门槛 ≤ 85% 时才成立
  4. vs 开源 API（$0.44/1M）：~1.3B tokens/天
  5. vs mini API（$0.24/1M）：~2.3B tokens/天——超大规模平台且人力 ≈ 0 才谈得上
  6. 2023 年的直觉已反转：2023 年 mid 档 API $10-60/1M，自部署在千万 token/天量级就打平；两年价格通缩 ~100x（2.2）把 break-even 推到十亿级。Jevons 的消费者侧镜像：API 单价崩得比自部署效率涨得快

质量修正（决定 A vs B 选择的临界值）：

(q_A − q_B) × 33M × v* = (c_A − c_B) = $516/天
v* ≈ 0.04 × 33e6 ÷ 516 ≈ $0.0004/query
  • 客服/企业场景：一次成功解决通常值 $0.1-1（省下的人工）→ v >> v* → 质量优先，选旗舰
  • 低价值流量（闲聊、预筛、粗排）→ mini 统治
  • 这就是 1.4 阶跃函数在每 1M token 上的微观形态

6.6 结论#

  • 生产者：闭源单代模型 ROI 为正（推理毛利 × 量），亏损在管线再投资；开源直接 ROI 全负，是补贴不是生意
  • 消费者：mini 档 API（$0.24/1M）是纯成本统治者；自部署的正当理由只剩合规/隐私/时延/控制 + 平台团队边际 ≈ 0 + 超大规模流量
  • 质量参数决定选项：用 4.3 六步模板实测 q 与 v，别用榜单——每 1M token 省的钱和每 1% 成功率赚的钱，只有在自己的任务分布上才能算清

6.8 实测对比：开源模型推理成本全谱系（H200 基准，2026.10）#

6.7 看训练侧的账，本节看推理侧的账。27 个当前热门开源型号（0.8B → 2.78T），规格全部实时核验：总参数取 HF safetensors API 实数，激活参数与架构取各家 README/config。标记口径：【官】=README/config 明示；【计】=从官方 config 推算（官方未标注）；【系】=沿用同系列上一代官方口径。成本为公式推算，非引擎实测。

口径与公式#
  • 基准硬件 H200 SXM：141GB HBM3e / 4.8 TB/s / FP8 dense 1979 TFLOPS；租金假设 $2.5/卡·hr（全表线性缩放，$2 则 ×0.8）。带宽勘误：本库此前误记 3.36 TB/s，已修（inference-perf-theory.md 同步修正）
  • 统一 FP8 部署口径（原生 FP8 仓库或官方/社区量化版）；BF16-only 部署则权重、卡数、单流成本全部 ×2
  • 吞吐模式（大 batch decode，算力受限，MFU=15%）：$ /1M 输出 token ≈ 0.0047 × N_active(B)。即 2.2 的 2·N_active·$/FLOP 代入 H200 数值；MoE decode 实测 MFU 通常 10-25%，取中
  • 单流模式（batch=1，带宽受限）：$ /1M ≈ 0.145 × 权重GB；TPOT_min = 权重GB ÷ (4.8 × 卡数) ms
  • 最少卡数 = ⌈权重GB × 1.08 ÷ 141⌉，再取 TP/EP 友好值（2/4/8/16/24）
  • 未计项：prefill（每 token 便宜 10-50 倍）、KV cache 显存挤占、峰谷 idle、牌价毛利

双重身份的实证（1.3/2.2 的落地）

  1. 两列排序完全不同：吞吐成本 ∝ 激活参数，单流成本 ∝ 总参数。K3 吞吐榜中游（104B 激活），单流榜断层第一（$402/1M）；M2.7/V4-Flash 吞吐便宜 10 倍，单流只要 $33-44
  2. 全谱系价差收口：吞吐口径 $0.004（0.8B）→ $0.49（K3）≈ 120 倍；单流口径 $0.13 → $402 ≈ 3100 倍。2.2 的"~100x 结构性价差"在吞吐口径成立，延迟口径再乘 30

规模侧

  1. 总参竞赛没停，但激活开始通胀：总参 1.6T-2.8T，全靠更稀疏的路由撑住单位成本（K3：896 选 16）。而 K2 32B → K3 104B（3.25 倍）——3.1"激活参数被推理经济学按住"出现反向支流：前沿开始花激活买能力，K3 吞吐成本已是 M2.7 的 10 倍
  2. 部署门槛两极分化：K3 三节点、LongCat/V4-Pro 两节点、四家单节点 8 卡、四家半节点 4 卡、M2.7 两卡、效率组与小模型组单卡。"开源旗舰"的入场券从单节点涨到多节点，"能跑"的门槛降到单卡
  3. 梯子完整度是产品哲学分歧：Qwen 0.8→397B 九档全配（Base/FP8/Int4 全套）；DeepSeek 主动弃小（R1-Distill 后再无小模型，最小开源 763B）——且官方给 Qwen 8B/14B 出 EAGLE3 投机解码草稿头：不做小模型，做小模型的配件，站在所有人的部署链路上

架构侧

  1. 注意力架构大分流（1M ctx 时代的入场券）：MLA+稀疏索引成旗舰标配——V3.2 的 DSA、GLM-5.3 的 indexer、LongCat 的 LSA（跨层索引）、K3 的 KDA；Qwen3.5 走 GDN 线性混合；唯一传统 GQA 的 Hy3（8 KV 头，KV 数百 KB/token）长上下文批量并发吃亏。DeepSeek 的 DSA 已被两家魔改跟进
  2. 原生 FP8 成中国旗舰标配：V3.2/V4 系/GLM-5.3/GLM-5.3-Flash/M2.7 官方 FP8 仓；Qwen3.5 官方 FP8 副仓；M3 官方 MXFP8 副仓
  3. 3.1"换轴"的活样本：GLM-5.3 官方自述"与 5.2 同底座，全部提升来自后训练"；V4.1-Flash 的 8B/16B 双档激活把"激活数"本身做成成本旋钮——新现象

小模型侧

  1. 小段位双流派：dense 快路线（9B：单流物理下界 500 tok/s、吞吐 $0.045）vs 小 MoE 省路线（35B-A3B：吞吐 $0.014、4 倍知识容量、单流慢 4 倍）——dense 用 3 倍吞吐成本换延迟与部署简单性
  2. ~3.6B 激活是全球商品化收敛点：Qwen 3B、GLM 3.6B【计】、LongCat 2.9-4.5B、Kimi 3B、OpenAI 3.6B——中外五家全落在 3-4.5B 激活/20-70B 总参带。6.4 cascade 模板的 r_small 当期标准答案
  3. 物理公式在 <10B 段失守：9B 的 TPOT_min 仅 2ms，被 3-8ms 框架/调度开销吃掉（inference-perf-theory 的 fixed-floor pitfall 实证）——小模型延迟瓶颈从"搬权重"转移到"工程开销"
  4. 量化路线参照：gpt-oss 用 MXFP4 原生走"单卡容量"路线（117B 进单卡 80GB）；Hopper 上字节优势保留、算力优势没有
与本框架的连接#
  • 本表 = 6.4 cascade 模板的当期选型菜单：r_small/r_big 的价格与卡数直接查表；按"单位智能 $ 通缩 ~10x/2yr"的节奏每季度重算
  • dense 模型大 batch 下 MFU 实际可达 30-50%（高于 MoE 的 15% 假设），表三吞吐成本是保守上界
  • K3 的激活通胀与 3.1 的判断构成一对张力：若 104B 级激活成为前沿新常态，"激活被按住"需改写为分段表述——商品层按住、前沿层放开
  • 旗舰组单流 tok/s 收敛在 40-60，印证 inference-perf-theory 的"TPOT 引力井"；小模型组跌破开销地板，是另一口井（工程开销井）
