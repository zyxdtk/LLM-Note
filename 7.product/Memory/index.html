Agent 记忆与知识自进化#

记忆是 Agent 的核心模块：没有记忆的 agent 是无状态的函数调用器，有记忆的 agent 才是持续进化的智能体。知识自进化本质上是"记忆的主动写入+组织+检索+更新"，类似于店铺在日常经营中沉淀 know-how。

一、综述与概念框架#

  • [2025.12] Memory in the Age of AI Agents 最新最全综述，46 位作者。三维框架：Forms（记忆形态：Token级/参数化/潜在）、Functions（记忆功能：事实型/经验型/工作型）、Dynamics（记忆动态：形成/演化/检索）。明确区分 agent memory 与 RAG、Context Engineering 的概念边界。开源 论文列表
  • [2024.04] 大模型智能体记忆机制综述 经典综述。参数化记忆 vs 上下文记忆。六大操作：巩固/更新/索引/遗忘/检索/压缩
  • [2025.05] From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms 记忆机制演进综述。从简单存储到经验学习
  • [2025.08] A Survey of Self-Evolving Agents: On Path to Artificial Super Intelligence 自进化 agent 综述
  • [2026.08] The Horizon Gap: Planning, Memory, Execution, Training, and Evaluation for Long-Horizon LLM Agents 长程 agent 的规划-记忆-执行-训练-评估全景
  • [2026.07] Dynamic Agent Skills: A Lifecycle Survey and Taxonomy of Evolving Skill Libraries 技能库生命周期综述：技能的创建、检索、演化、废弃

两大流派#

维度 模型驱动派 应用驱动派
代表 Memorizing Transformers, MemoryLLM, Titans, WISE MemGPT, Mem0, Zep, MemOS, MIRIX
核心思路 改造模型内部结构 应用层记忆管理
优势 性能上限高、读取效率高 落地快、易扩展、模型无关
劣势 研发成本高、需重新训练 依赖底层模型、可能有延迟
适合 算法创新 工程落地

记忆的分类（认知科学映射）#

记忆类型 定义 Agent 对应 店铺类比
短期/工作记忆 当前任务的临时上下文 context window / scratchpad 正在服务的这桌客人
情景记忆 (Episodic) 具体事件的经验 trajectory 存储、过往对话记录 昨天某个客人的特殊要求
语义记忆 (Semantic) 抽象知识和事实 知识库、用户画像、规则 "这家店的主打菜是什么"
程序记忆 (Procedural) 如何做某事的技能 skill library、代码片段、工作流 后厨的标准操作手册

二、记忆架构与开源框架#

应用驱动：基础工作#

  • [2023.04] Generative Agents: Interactive Simulacra of Human Behavior Stanford。记忆流 (Memory Stream) + 反思 (Reflection) + 规划。检索三标准：Recency（新近性）、Importance（重要性）、Relevance（相关性）。情景记忆+反思机制的奠基工作
  • [2023.05] Voyager: An Open-Ended Embodied Agent with Large Language Models Minecraft 终身学习 agent。三大组件：自动课程、技能库、迭代提示。技能库是程序记忆的典范：agent 将成功行为序列编码为可复用代码，存入技能库供后续调用
  • [2023.10] MemGPT: Towards LLMs as Operating Systems UC Berkeley。将 LLM 视为操作系统，虚拟内存管理：主上下文（Main Context）+ 外部存储（External Context），LLM 自主决定 swap in/out。分层：System Instructions / Working Context / FIFO。开源为 Letta
  • [2023.05] MemoryBank: Enhancing Large Language Models with Long-Term Memory 遗忘曲线先驱。三层存储：In-Depth Memory（详细对话+时间戳）、Hierarchical Event Summary（层次化摘要）、Dynamic Personality Understanding（用户个性动态评估）。借鉴艾宾浩斯遗忘曲线实现记忆遗忘
  • [2024.05] HippoRAG: Neurobiologically Inspired Long-Term Memory NeurIPS 2024。模拟人脑海马体：海马索引（Personalized PageRank）+ 新皮层存储（知识图谱）+ 模式分离。多跳问答超越传统 RAG 20%+
  • [2024.09] A-MEM: Agentic Memory for LLM Agents 卡片笔记法（Zettelkasten）。每个记忆是知识卡片：原始内容+时间戳+关键词+标签+上下文+链接集合。通过链接建立记忆网络，LOCOMO 上优于 MemGPT 和 MemoryBank
  • [2025.01] Zep: A Temporal Knowledge Graph Architecture for Agent Memory 时序知识图谱记忆层。三层图结构：情境子图（Episodic）→ 语义子图（Semantic）→ 社区子图（Community）。记忆去重+时间边失效机制。DMR 基准上超越 MemGPT
  • [2025.04] Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory 生产级首选。两种实现：Mem0（向量检索）和 Mem0-G（图增强）。记忆生成=上下文感知（当前问答+最近 M 条+会话 Summary），记忆更新=检索相似 N 条→LLM 判断增/改/删。冲突检测标记无效而非物理删除。LOCOMO 综合 SOTA
  • [2025.05] MemOS: A Memory OS for AI System 记忆张素（亿元天使轮）。记忆操作系统。三类记忆：纯文本（显式长期）、激活（隐式短期 KV-Cache）、参数（隐式长期）。动态转换：纯文本→激活（预生成 KV-Cache 降低 TTFT）、纯文本/激活→参数（蒸馏/LoRA 固化）、参数→纯文本（卸载过时知识）。统一抽象 MemCube，LOCOMO SOTA
  • [2025.07] MIRIX: Multi-Agent Memory System for LLM-Based Agents 多模块记忆。借鉴人类记忆分工，6 个记忆组件+Multi-Agent 架构管理。元记忆管理器路由→对应记忆管理器→两阶段检索（粗检索摘要→详细搜索）
  • [2024.08] MemLong: Memory-Augmented Retrieval for Long Context Modeling 检索记忆模块+可控注意力，超长文本处理

模型驱动：改造模型内部结构#

  • [2022.03] Memorizing Transformers Google。模型驱动开山之作。首次在 Transformer 中引入外部记忆：每个 token 存入外部记忆库，推理时 KNN 检索相关历史，融合外部记忆和内部注意力
  • [2024.02] MemoryLLM: Towards Self-Updatable Large Language Models ICML 2024。每层 Transformer 插入可更新的 Memory Tokens：固定参数（预训练）+ Memory Tokens（可读写）。Read/Write Gates 控制更新，遗忘控制对抗灾难性遗忘
  • [2024.07] Memory³: Language Modeling with Explicit Memory 三层显式记忆：感知记忆（原始输入）→ 短期记忆（工作上下文）→ 长期记忆（知识存储），每层不同编码和检索策略
  • [2024.05] WISE: Rethinking the Knowledge Memory for Lifelong Model Editing 浙江大学。双参数体系：主记忆（预训练知识冻结）+ 侧记忆（后续编辑可更新）。避免灾难性遗忘。开源 EasyEdit
  • [2024.12] Titans: Learning to Memorize at Test Time Google。学习遗忘。三个门控：存储门控（什么值得记）、遗忘门控（何时清理）、检索门控（调用哪些）。测试时学习（Test-Time Learning），Surprise 指标（梯度误差）决定新颖性。处理 2M+ 上下文

认知架构与理论框架#

  • [2023.09] CoALA: Cognitive Architectures for Language Agents 将 agent 记忆正式结构化为四类：Working Memory（工作记忆）、Episodic Memory（情景记忆）、Semantic Memory（语义记忆）、Procedural Memory（程序记忆）。统一了所有论文的术语，理解 Agent 架构的通用蓝图

三、知识自进化 = 店铺记忆#

核心观点：知识自进化本质上就是 agent 的"店铺记忆"——在日常运行中主动积累经验、组织知识、检测冲突、更新认知。

知识自进化的四个环节（对应店铺经营）#

  1. 经验积累（写入记忆）：agent 执行任务 → 记录 trajectory → 提取可复用知识
  2. 店铺类比：每天接待客人，记录什么做法有效
  3. 知识组织（记忆管理）：将碎片化经验结构化为可检索的知识
  4. 店铺类比：把零散经验整理成操作手册
  5. 知识复用（记忆检索）：新任务来时，检索相关经验指导决策
  6. 店铺类比：遇到类似客人，参考过去的成功经验
  7. 知识更新（记忆演化）：发现旧知识过时或错误时，更新或遗忘
  8. 店铺类比：菜单变了，更新操作手册，废弃旧做法

  • [2026.07] CrystalMem: Elastic Memory for Self-Evolving LLM Agents via Knowledge Crystallization 知识结晶化：将松散经验结晶为紧凑知识。发现记忆配额压缩后能力不会自动恢复，提出弹性记忆架构

五、记忆评估基准#

主流基准#

  • LOCOMO 长对话记忆评测。Mem0/MemGPT/Zep/A-MEM 等均在 LOCOMO 上对比。Mem0 综合 SOTA，MemOS SOTA
  • LongMemEval 企业级长期记忆评测。Zep 准确度提升 18.5%
  • DMR Benchmark 动态记忆检索评测。Zep 94.8% vs MemGPT 93.4%
  • MemoryBench 多任务记忆能力评测

最新基准#

八、知识自进化可借鉴方案总结#

针对你正在做的"知识自进化"，以下是最直接可借鉴的方案路线：

路线 A：技能库自进化（程序记忆路线）#

参考 Voyager → MetaSkill-Evolve → SkillProx 路线： 1. agent 执行任务，记录成功 trajectory 2. 从 trajectory 中提取可复用技能（代码/自然语言指令） 3. 技能存入库，新任务时检索相关技能 4. 技能使用后根据反馈迭代优化 5. 定期压缩技能库（SkillZip），废弃低效技能

路线 B：经验蒸馏自进化（情景→语义记忆路线）#

参考 ExpeL → Reflexion → Knowledge-Centric Self-Improvement 路线： 1. agent 执行任务，记录成功/失败 trajectory 2. 反思失败原因，提取教训（Reflexion 式） 3. 从多次经验中归纳通用 insights 和 rules（ExpeL 式） 4. 将 insights 组织为可检索的知识库（知识中心式） 5. 新任务时检索相关 knowledge 指导决策 6. 检测知识冲突，更新过时知识

路线 C：知识结晶化（记忆压缩路线）#

参考 CrystalMem → AMC → Rate-Distortion 路线： 1. 原始经验以情景记忆形式存储（详细 trajectory） 2. 定期"结晶化"：将松散经验压缩为紧凑知识 3. 用率失真理论指导压缩（什么该留什么该忘） 4. 结晶后的知识可跨任务复用 5. 处理记忆配额波动（弹性记忆）

关键设计决策#

  1. 记忆存什么：trajectory 原文 vs 提炼后的 insights？前者保真但冗余，后者紧凑但可能丢失上下文
  2. 记忆怎么检索：向量相似度 vs 图遍历 vs LLM 判断？各有利弊
  3. 记忆何时更新：实时 vs 批量？实时开销大，批量可能用过时知识
  4. 记忆冲突怎么解决：覆盖 vs 保留多版本 vs 时间戳优先？
  5. 记忆安全：如何防止错误经验/投毒轨迹污染知识库？
