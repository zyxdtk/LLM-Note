# AGI 费曼学习笔记

> 本文档用费曼学习法组织——从定义出发，逐层拆解 AGI 的现状、路线和缺失。

## 一、AGI 到底是什么——先解决定义问题

每个人说 AGI 的时候，说的不是同一件事：

```
定义 A：AGI = 能做人类能做的所有事（能力定义）
定义 B：AGI = 能做大多数有经济价值的事（经济定义）
定义 C：AGI = 能自主学习和改进的系统（学习定义）
```

2026 年的大模型在三个定义上差距极大：

```
定义 A（能力）：GPT-5.2 / Claude Opus 4.6 在很多认知任务上已超过人类平均水平。
  但不会开车、不会做饭、不会修水管。

定义 B（经济）：已替代大量文案、客服、初级编程工作。
  但替代不了水管工、厨师、外科医生。

定义 C（学习）：能通过 few-shot 学习新任务，但还不能自主发现新技能。
  Self-evolving agent 在起步阶段但远未成熟。
```

所以"AGI 来了吗"真正的问题不是"来了没有"，而是"你用哪个定义"。

更好用的框架：不要问"是不是 AGI"，问"在哪些维度上达到人类水平了"。

## 二、逐维度盘点——我们在哪里

```
维度                     AI 现状(2026.08)      人类水平      差距
────────────────────────────────────────────────────────────
文本理解与生成            超越人类平均水平       —            已过
编程（已知问题）          接近高级工程师         —            基本到了
数学推理                  超过大多数人类         顶尖数学家    接近
科学知识广度              远超任何单个人类       —            已过
长程规划                  弱                     强            大
多步推理（>10步）         中等                   强            中等
创造性思维                模仿型强，原创型弱      强            中等
物理世界操作              极弱                   强            巨大
自主学习新技能            极弱                   强            巨大
跨模态推理                中等                   强            中等
情感与社会智能            模仿型                 真实           中等
持续记忆                  差（跨会话遗忘）       强            大
```

AI 在"知识"和"推理"维度上已经很强，但在三个维度上严重落后：

1. 物理世界操作（Physical AI 还在 ChatGPT 前夜）
2. 自主学习新技能（self-evolving 刚起步）
3. 持续记忆（跨会话、跨天、跨月记住经验）

---

## 三、三块短板为什么是连在一起的

人类学习走路的闭环：

```
物理世界操作 → 获得反馈 → 持续记忆 → 调整策略 → 再次操作
     ↑                                              │
     └──────────────────────────────────────────────┘
```

AI 目前每一步都断：
- LLM 不能操作物理世界（没有身体）
- 不能获得真实的物理反馈（摔了不知道疼）
- 不能持续记住昨天的经验（每次对话从零开始）
- 不能自主调整策略（需要人类标注或人类设计训练流程）

AGI 不是一个纯软件问题。没有物理交互、没有持续记忆、没有自主学习能力，再大的模型也只是"一个非常博学但不能成长的脑子"。

这就是为什么 OpenAI、Anthropic、Google 都在做机器人——不是因为想造机器人卖钱，而是因为 AGI 的瓶颈不在文本能力上，在物理交互和持续学习上。

## 四、通往 AGI 的五条路线

### 路线一：Scale 上去（OpenAI 原教旨路线）

核心信念：只要模型足够大、数据足够多、算力足够强，AGI 会自然涌现。

2025 年开始碰到墙：
- 文本数据快用完了（互联网高质量文本 ~15-20 万亿 token，GPT-5 级别已用几万亿）
- 收益递减（GPT-4→GPT-5 的提升不如 GPT-3→GPT-4）
- 有些能力不是 scale 能解决的（给 GPT-5 机械臂不会因为参数变大就学会抓杯子）

### 路线二：Agent 化

核心信念：AGI 不是一个大模型，而是一个系统。模型 + 记忆 + 工具 + 规划 + 自进化。

单个 LLM 再强也不是 AGI。AGI 需要一个能持续运行、积累经验、改进自己的系统。

代表：ACE、Meta-Harness、Darwin Gödel Machine、ALMA。

关键瓶颈：评估——怎么知道 agent 真的变好了，而不是自我确认的幻觉？

### 路线三：Physical AI + AI 融合（NVIDIA / Tesla）

核心信念：没有身体的智能不是真正的智能。人类智能从物理交互中进化出来。

黄仁勋说 Physical AI 是 AI 的下一个前沿。Musk 把 Optimus 看得比 FSD 更重要。

最慢——Physical AI 还在 ChatGPT 前夜，数据量差 LLM 1500 万倍。

### 路线四：经验驱动 RL（DeepMind / Ineffable Intelligence）

核心信念：不应主要依赖人类数据，应通过自主与环境交互来学习。

```
传统 LLM：人类数据 → 训练 → 模型（上限是人类知识）
经验驱动 RL：环境 → 交互 → 反馈 → 学习 → 模型（上限是环境复杂度）
```

David Silver（AlphaGo/AlphaZero）：AI 应该通过 experience 而不是人类数据来持续学习。

瓶颈：样本效率——AlphaGo 可以下一亿局棋，机器人不能摔一亿次。

### 路线五：脑启发 / 新架构

核心信念：Transformer 不是终点。真正的 AGI 可能需要新架构。

Transformer 的根本局限：
- 没有持续学习（训练完就冻结）
- 没有工作记忆（context window 是临时缓冲，不是真正的记忆）
- 没有因果推理（只是模式匹配，不理解因果）

TTT layers、Titans 是这条路的前哨——给模型加上持续学习和长期记忆。

---

## 五、哪条路线最可能到达 AGI

没有一条路线能单独到达。最可能的路径是几条路线交汇：

```
Scale 提供基础能力（已经基本到位）
  +
Agent 化提供系统级持续运行（正在做）
  +
Physical AI 提供物理世界锚点（还需要 3-5 年）
  +
RL 提供超越人类数据的学习能力（还需要突破样本效率）
  =
可能的 AGI
```

用 RSI 综述的结论：
- 已经发生的：AI 辅助 AI 开发
- 正在发生的：有限形式的递归自改进（bounded RSI）
- 尚未证明的：开放式自主 RSI

用 Anthropic 的话说："We are not there yet."

## 六、AGI 真正缺的是什么

不是数据、不是算力、不是模型大小。是三样东西：

### 缺失一：持续学习的能力

当前所有大模型都是"训练完就冻结"的。要学新东西，必须重新训练或微调。

人类不是这样——今天学一个新概念，明天就能用，不需要"重新训练大脑"。

TTT 在试图解决（推理时更新参数），但还远远不够。真正的持续学习需要：
- 不忘记旧知识（避免灾难性遗忘）
- 能整合新知识到已有知识体系
- 能判断哪些新信息值得记住

### 缺失二：世界模型

LLM 有语言模型但没有世界模型。它能说"杯子掉到地上会碎"，但不是真的理解重力和脆性——只是见过太多类似文本。

真正的 AGI 需要：不只是知道"什么跟什么一起出现"，而是理解"为什么"。

Cosmos 在做这件事——给 AI 一个物理世界的模型。但世界模型还远没成熟。

### 缺失三：自主目标设定

当前所有 AI 系统都是被动的——人给它一个任务，它执行。没有 AI 能自己决定"我应该学什么"。

人类会自己好奇、自己探索、自己设定目标。一个不会自己产生目标的系统，无论多强都只是工具，不是 general intelligence。

这一条可能是最难的——不是技术问题，是科学问题。我们连人类的目标设定机制都没搞清楚。

---

## 七、总结

AGI 不是"更聪明的大模型"。

AGI 是一个能持续学习、有世界模型、能自主设定目标的系统。

我们在"知识"和"推理"上接近了，但在"持续学习"、"物理交互"和"自主目标"上还差很远。

最可能的路径不是某一条路线单独突破，而是 Scale + Agent + Physical AI + RL 几条路线交汇。

时间线：如果各条路线保持当前速度，交汇点大概在 2028-2032 年之间。这不是预测，是线性外推。实际可能更快（突破性发现）也可能更慢（意料之外的墙）。
